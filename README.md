# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在`data/db.json`，后续可以继续增量迭代。

## 氡巡查与通风放行

在原有温湿度、CO2 巡测之外，系统支持氡巡查登记与超限后的通风放行闭环：

- **氡巡查**：登记样点、仪器、时段、氡浓度、平衡当量浓度与操作员；仪器未归还时不能借给别的样点。
- **超限判定**：氡浓度超过 400 Bq/m³ 或平衡当量浓度超过 120 时，样点转入待通风并暂停讲解许可，自动开立放行单。
- **通风放行**：按风量 × 时长累计换气量，达到洞室容积 3 倍后，由另一位巡测员间隔 30 分钟复测，两次均低于限值才恢复常规观察。
- **修订重判**：修订读数或洞室容积会让未结束的放行失效并按新值重判，旧记录保留可查；放行看板显示还差几次复测与累计换气量。

代码按三层组织：判定规则在 `src/radon.js`，存档读写在 `src/store.js`，页面在 `public/radon.js`（通用 CRUD 页面仍在 `public/app.js`）。
